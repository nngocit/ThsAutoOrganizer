            Phiên bản Sản phẩm
            v2.1.0

          Three-Way Sync Architecture & SOLID Clean Workers: Triển khai kiến trúc luồng dữ liệu 3 chiều thông suốt giữa Web UI, Cloudflare Worker (Service Account), Google Drive và Local Agent; thanh lọc toàn bộ mã nguồn thừa và khôi phục Golden Baseline chuẩn xác.
        

      


      
      

        

          🔄 1. Thiết kế Luồng Dữ liệu 3 Chiều (Three-Way Sync Flows)
        

        
    
          
  • 
            Master Creation Flow (Tạo mới Môn học): Người dùng tạo môn học trên Web UI -> Cloudflare Worker dùng Service Account JWT tự động tạo thư mục trên Google Drive 24/7 -> Lưu Firestore ở trạng thái pending -> Local Agent ở nhà tự động chạy lệnh nlm notebook create lấy NotebookLM ID và tạo cây thư mục vật lý H:\2026\Thac Sy\Mon....
          
    • 
          
  • 
            Web-to-Cloud-to-Local Upload Flow (Tải lên Tài liệu): Cho phép upload trực tiếp tài liệu từ Web UI -> Cloudflare Worker stream dữ liệu lên Google Drive, gán quyền Public Reader -> Tạo hàng đợi task source_add -> Local Agent nạp file vào NotebookLM Plus và sao lưu về máy tính.
          
    • 
          
  • 
            Reconciliation & Auto-Discovery Flow (Đối soát & Quét tự động): Cung cấp API đối soát toàn diện giữa Google Drive và Firestore, hỗ trợ nhập nhanh (1-click import) các môn học sẵn có trên Google Drive thành môn học chính thức.
          
    • 
        

      


      

        

          ⚡ 2. Tinh gọn Mã nguồn Workers Chuẩn SOLID (Clean Workers)
        

        
    
          
  • 
            Xóa sạch Code Rác & Trùng lặp: Xóa bỏ hoàn toàn các file và endpoint thừa (routes/insights/, upload_init.js, upload_complete.js, cấu hình notebook hardcode).
          
    • 
          
  • 
            Google Drive Client Tinh gọn (src/lib/drive.js): Sử dụng Web Crypto API thuần chạy trực tiếp trên Cloudflare Workers Edge, xác thực Google Service Account JWT 24/7 không cần User OAuth refresh token.
          
    • 
          
  • 
            Phân rã Router Độc lập: Chuẩn hóa các route /api/courses, /api/files/upload, /api/sync, /api/ai/insights theo đúng nguyên tắc Single Responsibility.
          
    • 
        

      


      

        

          🛡️ 3. Khôi phục Nền tảng Cốt lõi (Golden Baseline Core v2.0)
        

        
    
          
  • 
            Nguyên tắc Zero-Noise: File chạy chính main.py đã được khôi phục về trạng thái sạch tuyệt đối: chỉ in ĐÚNG 5 dòng log khởi tạo hệ thống (Config, MCP, Firebase, Auth email, Cloudflare ping) và thoát với mã lỗi 0.
          
    • 
          
  • 
            Kiểm thử Tự động Hóa 100%: Đạt 10/10 test Vitest cho Cloudflare Workers và 28/28 test Pytest cho Local Agent & Golden Baseline.
