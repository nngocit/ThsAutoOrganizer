🔗 Cấu hình NotebookLM MCP

Để kích hoạt đồng bộ NotebookLM Plus, chạy lệnh sau trong terminal:

pip install notebooklm-mcp-cli
nlm login

Sau khi đăng nhập, Python Local Agent sẽ tự động đồng bộ tài liệu vào đúng Notebook.
