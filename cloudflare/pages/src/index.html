🔗 Kết nối NotebookLM MCP & Local Agent

Để kích hoạt đồng bộ tài liệu vào NotebookLM Plus, hãy đảm bảo bạn đã cài đặt MCP CLI và đăng nhập trên máy tính: 

pip install notebooklm-mcp-cli
nlm login
